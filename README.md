# Haoyang Zhang · Professional portfolio

Public website: https://zhanghaoyang1993.github.io

This repository contains generated static pages, styles and the public Professional CV.
Content is maintained in a separate private source repository. Edit the shared career YAML there,
build and review locally, then publish the approved export here.

The website has no database, analytics, third-party scripts or runtime dependencies.
GitHub Actions verifies the public artifact manifest and deploys to GitHub Pages.
Targeted application CVs and private career records are not included.
